# 🏋️ AI Fitness — Adaptive Workout Planner

An **AI-powered fitness application** that generates personalized workout plans using Google Gemini AI, tracks your progress, and adapts to your fitness level over time. Built with a **FastAPI** backend and a **React Native (Expo)** mobile frontend.

---

## ✨ Features

| Area | Highlights |
|---|---|
| **AI Workout Generation** | Personalized plans generated by **Gemini 1.5 Flash** based on your goals, equipment, fitness level, and time |
| **User Assessment** | Onboarding questionnaire captures age, weight, fitness goal, experience, equipment, and medical concerns |
| **Workout Tracking** | Start sessions, log sets/reps, and mark exercises as completed in real-time |
| **Progress Dashboard** | Weekly stats, workout history, and performance trends |
| **Feedback System** | Post-workout difficulty & enjoyment feedback to refine future plans |
| **Exercise Library** | 40+ pre-seeded exercises across all muscle groups with difficulty levels |
| **JWT Authentication** | Secure register / login flow with token-based auth |
| **Dark Mode UI** | Sleek dark-themed mobile interface with gradient accents |

## 🛠️ Tech Stack

### Backend
- **Framework:** [FastAPI](https://fastapi.tiangolo.com/) `0.115`
- **Database:** [MongoDB](https://www.mongodb.com/) via [Motor](https://motor.readthedocs.io/) (async driver) `3.5`
- **AI:** [Google Gemini 1.5 Flash](https://ai.google.dev/) via `google-generativeai` SDK
- **Auth:** JWT (`python-jose`) + Bcrypt password hashing
- **Validation:** Pydantic v2
- **Server:** Uvicorn (ASGI)

### Mobile
- **Framework:** [React Native](https://reactnative.dev/) `0.81` with [Expo](https://expo.dev/) SDK `54`
- **Navigation:** [Expo Router](https://docs.expo.dev/router/introduction/) v6 (file-based routing)
- **Language:** TypeScript `5.9`
- **Storage:** `@react-native-async-storage/async-storage`
- **UI:** React Native SVG, Expo Linear Gradient

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/DovariRahul/fitness_app.git
cd fitness_app
```

### 2. Backend Setup

```bash
# Navigate to backend directory
cd backend

# Create and activate a virtual environment
python -m venv venv

# Windows
venv\Scripts\activate

# macOS / Linux
source venv/bin/activate

# Install dependencies
pip install -r requirements.txt
```

#### Configure Environment Variables

Copy the example env file and fill in your values:

```bash
cp .env.example .env
```

Edit `.env` with your credentials:

```env
# MongoDB — local or Atlas connection string
MONGODB_URI=mongodb://localhost:27017
DATABASE_NAME=fitness_app

# JWT Secret — change this to a strong random string in production
JWT_SECRET_KEY=your-super-secret-key-change-in-production
JWT_ALGORITHM=HS256
JWT_EXPIRATION_MINUTES=1440

# Google Gemini API Key (must start with "AIza")
GEMINI_API_KEY=your-gemini-api-key-here

# CORS — allowed origins (add your Expo dev URL if different)
CORS_ORIGINS=["http://localhost:8081","http://localhost:19006","http://10.0.2.2:8081"]
```

#### Run the Backend Server

```bash
# From the backend/ directory (with venv activated)
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

The API will be available at:
- **API Root:** [http://localhost:8000](http://localhost:8000)
- **Swagger Docs:** [http://localhost:8000/docs](http://localhost:8000/docs)
- **ReDoc:** [http://localhost:8000/redoc](http://localhost:8000/redoc)

> On first startup, the database is automatically seeded with 40+ exercises.

---

### 3. Mobile App Setup

```bash
# Navigate to mobile directory (from project root)
cd mobile

# Install dependencies
npm install
```

#### Run the Mobile App

```bash
# Start the Expo development server
npm start
# or
npx expo start
```

Then choose how to open:
- Press **`a`** — open on Android emulator
- Press **`i`** — open on iOS simulator (macOS only)
- Press **`w`** — open in web browser
- **Scan the QR code** — open on your physical device via Expo Go

#### Connect to Backend (Physical Device)

The app is pre-configured with **automatic host detection** via Expo Constants (`Constants.expoConfig.hostUri`). When your mobile phone connects to the Metro bundler over Wi-Fi, it automatically routes backend calls to your computer's IP address.

You can also explicitly set or override the backend URL in `mobile/.env`:

```env
# mobile/.env
EXPO_PUBLIC_API_URL=http://<YOUR_COMPUTER_IP>:8000/api/v1
```

> **Note for Physical Phone Testing:** Both your phone and computer must be connected to the same Wi-Fi network. Ensure your computer's firewall allows inbound connections on port 8000 (FastAPI) and 8081 (Metro).

## 📡 API Endpoints

All endpoints are prefixed with `/api/v1`.

### Authentication
| Method | Endpoint | Description |
|--------|----------|-------------|
| `POST` | `/auth/register` | Register a new user |
| `POST` | `/auth/login` | Login and get JWT token |

### Users
| Method | Endpoint | Description |
|--------|----------|-------------|
| `GET` | `/users/me` | Get current user profile |
| `POST` | `/users/assessment` | Submit fitness assessment |
| `PUT` | `/users/profile` | Update user profile |

### Exercises
| Method | Endpoint | Description |
|--------|----------|-------------|
| `GET` | `/exercises` | List all exercises (with filters) |
| `GET` | `/exercises/{id}` | Get exercise details |

### Workouts
| Method | Endpoint | Description |
|--------|----------|-------------|
| `GET` | `/workouts/today` | Get today's workout plan |
| `GET` | `/workouts/{id}` | Get workout by ID |
| `POST` | `/workouts/generate` | Generate AI workout plan |

### Sessions
| Method | Endpoint | Description |
|--------|----------|-------------|
| `POST` | `/sessions/start` | Start a workout session |
| `PUT` | `/sessions/{id}/complete` | Complete a session |
| `GET` | `/sessions/history` | Get session history |

### Feedback
| Method | Endpoint | Description |
|--------|----------|-------------|
| `POST` | `/feedback` | Submit post-workout feedback |

### Progress
| Method | Endpoint | Description |
|--------|----------|-------------|
| `GET` | `/progress/stats` | Get overall stats |
| `GET` | `/progress/weekly` | Get weekly progress data |

> 📖 Full interactive API docs available at `/docs` when the server is running.
